# 玉环-解缘 · 电子鲁班锁 V12

一款以东方美学、治愈体验与榫卯顺序解谜为核心的手机竖屏网页游戏。

## V12 完成内容

- 藏宝阁中的30关全部可直接点击进入，通关状态只用于收藏记录，不再锁住后续关卡。
- 每张藏宝阁封面直接展示该关真实珠宝环，并增加独立材质色、内框和收藏状态。
- 30种珠宝环不再共用一张素材换色，而是30件独立的顶级材质实物资产。
- 材质包括和田白玉、羊脂白玉、冰种翡翠、帝王绿、苹果绿翡翠、竹叶青玉、紫罗兰翡翠、紫水晶、粉水晶、桃花玉、红翡翠、南红玛瑙、海蓝宝、蓝宝晶、绿松石、青金石、蜜蜡琥珀、黄玉、黑曜石、墨翠、烟晶、虎眼石、青玉、岫玉、月光石、欧泊、白水晶、金发晶、冰粉翡翠、碧玺。
- 每种材质保留真实的油脂光、冰透感、天然棉絮、晶体包裹体、猫眼光带、金丝或火彩特征。
- 所有关卡的玉环之间都保留清楚间隔，不再互相贴住或叠压。
- 所有金扣统一为同一款细长鎏金扣，以两颗小钻作固定铆点，不再使用多套复杂装饰。
- 金扣精确位于两环之间，横跨间隔并在两端压住环边，保持清楚的连接关系。
- 修复黑曜石透明抠图错误，重新制作完整、清晰、具有玻璃高光的黑曜石环。
- 30种材质统一套用同一条1:1标准正圆C环轮廓，保持圆头开口和安全留白，不再拉扁、削角或裁边。
- 金扣改为关卡级样式：同一关所有金扣完全一致，不同关卡依次使用素金、单钻、双钻和三钻款。
- 30关全部统一为参考图中的七环母版：上二、中三、下二，保持大尺寸玉环与充足留白。
- 后期关卡不再堆到12只环；难度改由金扣数量、解锁顺序、阴阳旋向与多重依赖提升。
- 增加参考图式的古风题签“你能解开所有玉环吗”，并重新安排题签、卦签、玉盘与七环的视觉层级。
- 七只环使用固定连续连接图，保证每只环至少拥有一个金扣，部分环拥有两个金扣。
- 初始旋转角会主动避开所有相连金扣，确保开口不会正对扣件；进入关卡时每个金扣都压在完整环体上。
- 金扣宽度略增并继续固定在两环正中间，使扣件两端明确覆盖两侧玉环。
- 游戏正式更名为《玉环-解缘》，首页、关卡标识和页面标题同步更新。
- 玉环开口改为干净截面，删除端头突出的球状造型。
- 金扣旋转为短端分别对接两只玉环，两个长边不再压住任何环体。
- 难度分四段增加：6、7、8、9枚金扣；中后期会出现一个环同时受3枚金扣牵制。
- 删除“你能解开所有玉环吗”，30关分别显示对应材质的吉祥语，并按卦象显示《易经》智慧。
- 放大卦签名称、生门提示、操作提示、按钮说明和底部规则文字。
- 游戏内文字整体放大并统一为古风楷书、宋体字形，关卡名、卦签、操作提示、步数、按钮和底部规则均提高对比度。
- 30关难度递增：环数、金扣数、前后依赖、阴阳旋转方向与多重牵制逐步增加。
- 周易八卦只作为解谜提示语言，不做说教与占卜。

## 运行

直接打开 `index.html`。项目为纯静态网页，不需要安装依赖。
